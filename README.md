## Purpose

VextPhisher is a **security education laboratory** designed to:

- Demonstrate how real phishing pages are built
- Show how attackers mimic legitimate services
- Help users recognize phishing attempts
- Improve phishing detection and awareness
- Support defensive cybersecurity learning

This project is intended for:
- Students
- Developers
- Security researchers
- Security awareness training
- Offline labs and demonstrations
